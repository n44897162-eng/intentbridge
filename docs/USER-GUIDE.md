# 用户手册（P0）

面向不需要写代码的使用者。所有数据都在本机；关闭页面不会上传任何内容。

## 1. 启动

管理员执行 `pnpm shell:web` 后会打印一个带 `token=` 的地址。用浏览器打开即可；令牌只保存在当前浏览器，不要转发给他人。

页面左侧有四个入口：流程、录制、运行、设置。

## 2. 得到一个流程

两种方式：

1. **导入**：流程页选择 `*.json` 或加密 `*.ibflow`，输入口令（如需要）。导入会做 schema 校验和版本迁移，错误会直接列出规则与位置。
2. **录制**（Web）：
   - 打开目标页面，点击浏览器扩展图标 → 授权当前站点 → 开始录制；
   - 正常操作（输入、点击）；扩展会显示持续状态；
   - 停止后扩展生成草稿并保存到本机流程库；
   - 回到管理端检查步骤与锚点。
     密码字段不会被录制。

## 3. 编辑流程

打开流程 → 顶部「保存」写入新 revision（历史不可变）。

- **步骤**：左侧按顺序列出；右侧编辑动作、名称、风险、超时、失败处理、幂等键。
- **目标锚点**：语义（role/name/test-id）、原生标识、结构路径、视觉 dHash。界面会提示“有界路径”；不要填无限深绝对路径。
- **参数 / 前置 / 后置条件**：JSON 视图。写动作必须有后置条件；保存时校验会拒绝缺失。
- **目标检查器**：显示最近运行的候选评分（语义/结构/原生/视觉、是否自动可执行、理由）。如果都是 0，说明目标未解析。
- **变量与密钥**：变量可设类型/必填/敏感；密钥只显示别名。输入值写成 `secret://alias`，运行时才会取值。
- **权限**：按需勾选；缺少权限会在保存/运行时被拒绝。
- **JSON**：专家视图；应用后仍会走校验。

## 4. 试运行

运行记录 → 填变量 → 可选“自动批准”“歧义选第一个（仅测试）”“单步”“从某步开始” → 开始运行。

- 状态 `RUNNING`：时间轴实时刷新。
- `PAUSED_FOR_APPROVAL`：核对动作/目标/参数摘要后批准或拒绝。
- `PAUSED_FOR_DISAMBIGUATION`：引擎不会猜，显示候选（名称/role/test-id/分数）；点击正确的一个。
- `PAUSED_FOR_OUTCOME`：写操作结果不明。先人工查看真实系统，再选“确认已完成/未完成/重试”。**不要盲目重试**。
- `PAUSED_FOR_RECOVERY`：`ask-user` 失败、用户暂停、越界、单步完成；选择继续/重试/跳过/补偿/停止。

“已执行”只依据后置条件；动作调用返回不等于成功。

## 5. 失败证据

运行详情 → 证据：只保存目标附近的裁剪图（敏感步骤可禁截/遮罩），默认 7 天过期。导出诊断包会再次脱敏，不含密钥值。

## 6. 导出/分享

- 普通 JSON：可读、可 diff；包含 `secret://` 别名，不含值。
- 加密导出：最少 8 位口令，scrypt + AES-GCM；对方需要同一口令导入。
- 签名状态显示 `unsigned`，v1 不做签名发布。

## 7. 浏览器扩展的限制

- 必须显式授权站点；不默认申请 `<all_urls>`。
- 动作是 DOM 级输入；对强反自动化站点可能不起作用，这属于能力限制，不做绕过。
- 跨域 iframe、验证码、DRM、登录限制不支持。
- 扩展不计算视觉 dHash；纯视觉锚点会要求人工确认。

## 8. 不要用本工具做什么

- 银行转账、证券下单、批量删除等不可逆无人值守操作；
- 远程控制他人设备、键盘记录、收集密码；
- 绕过验证码/风控/设备完整性。
