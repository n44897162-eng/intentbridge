# 威胁模型（v1 / P0）

适用范围：本机管理端、Web Runner、MV3 扩展、Rust 引擎、Windows/Android 源码切片。默认假设：单用户、本机、无云服务、攻击者可能提供恶意流程包/恶意网页/诱导点击，或能读到本机文件。

## 资产

- 凭据：密码/令牌/OTP（只以 `secret://alias` 出现在 IR）。
- 屏幕内容、目标裁剪截图、运行日志。
- 流程定义与 revision 历史。
- 本机执行能力（点击、输入、启动应用、导航）。
- 审计完整性（事件不能被静默改写/丢弃）。

## 威胁与控制

| #   | 威胁                              | 入口             | 控制                                                                                                         | 残余风险                                          |
| --- | --------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| T1  | 恶意流程包绕过校验执行危险动作    | 导入 JSON/加密包 | Schema + 语义校验、`risk` 审批、写动作后置条件、`app_scope` 限制、引擎不开放任意脚本                         | 用户主动批准高风险动作后仍可能产生真实副作用      |
| T2  | 恶意网页伪造控件（假按钮/覆盖层） | Web DOM          | 仅允许声明 origin；多锚点评分；结构/视觉证据；歧义暂停；动作前可见/可用检查                                  | 同 origin 内的恶意页面仍可伪装；不承诺防钓鱼      |
| T3  | 选择器注入 / DOM XSS              | 流程文本进入 UI  | UI 只用 `textContent`/DOM API，不 `innerHTML`；CSP `script-src 'self'`；不把流程文本当 HTML                  | 证据图片本身可能包含敏感内容（裁剪+遮罩+保留期）  |
| T4  | IPC token 泄露/CSRF               | loopback API     | 随机 32 字节 token、常量时间比较、Origin/Sec-Fetch-Site 检查、仅 127.0.0.1、无 CORS 放行                     | 本机同用户进程可读取 UI URL（仍是同用户信任边界） |
| T5  | 路径穿越读任意文件                | 证据下载         | 证据 ID 查库、realpath 校验必须在 data/evidence 下；越界 403；有测试                                         | 数据库被本机攻击者改写时仍受路径检查限制          |
| T6  | 密钥泄漏到日志/导出               | 变量/导出/诊断   | 只存别名；参数预览脱敏；诊断包二次脱敏；加密导出默认；`secret://` 不解析为值进入事件                         | 运行内存中仍有明文（执行时需要），不落盘          |
| T7  | 日志/截图泄漏敏感内容             | 证据策略         | 默认只截目标裁剪、`mask_text`、可选 `mask_selectors`；7 天过期；存储上限；敏感步骤必须关闭或遮罩（校验强制） | CSS 遮罩不是像素级不可逆处理；高敏场景应关闭截图  |
| T8  | 重放产生重复副作用                | 崩溃/超时/重试   | `action_attempt_id`、幂等键、写动作默认不重试、`OUTCOME_UNKNOWN` 暂停、事件先落盘                            | 外部系统自身不幂等时，人工“确认重试”仍可能重复    |
| T9  | 权限过度授予                      | 运行/扩展        | 流程声明权限；缺权限在装载/运行前拒绝；扩展不申请 `<all_urls>`，按站点授权，无静态 content script            | 用户可自行授予宽权限                              |
| T10 | 无障碍/桌面自动化滥用             | Android/Windows  | 服务必须用户手动开启；持续通知；仅前台目标应用；不做隐藏、不做反检测、不注入系统事件                         | 用户已授予的无障碍能力本身很强                    |
| T11 | 模型/云端外泄                     | 模型适配器       | v1 不依赖模型；设置接口拒绝启用模型适配器；无出站网络                                                        | 未来 P2 需独立授权与数据去向声明                  |
| T12 | 供应链                            | 依赖             | pnpm/Cargo 锁文件；`allowBuilds` 只允许 esbuild 构建脚本；CycloneDX SBOM；无来路不明执行器                   | 未接入 CVE 扫描服务（记录在 BUGLOG）              |
| T13 | 审计日志被篡改                    | 本地文件         | append-only 事件 + `(run_id,seq)` 幂等；诊断包 hash；SQLite 事务                                             | 本机同用户仍可直接改库；未做签名哈希链            |
| T14 | 证据存储耗尽磁盘                  | 失败截图         | 配额检查 + 过期清理 + 停止写入告警（上限内）                                                                 | 目前超限只停止证据写入，不弹 UI 告警              |
| T15 | 密码字段被录制                    | Web/Android      | 扩展/录制器跳过 password 字段；Android 用 `isPassword`；IR 校验对 password 类目标强制 secret/敏感变量        | 自定义控件若未声明 password 特征可能漏判          |

## 明确不做

- 不绕过验证码、反自动化、DRM、设备完整性、登录限制。
- 不做隐形运行、远程控制他人设备、键盘记录、密码采集。
- 不宣称外部系统事务回滚；只有显式补偿步骤。
- 不把第三方模型/云服务设为必需依赖。

## 安全测试现状

- 已自动验证：非法 IR、未知字段、明文密码、密钥位置、诊断包不含密文值、错误口令、路径穿越、跨站请求拒绝、扩展无 `<all_urls>`、CSP 含 `wasm-unsafe-eval` 且不含 `unsafe-eval`。
- 未自动验证：磁盘满、权限在运行中被系统撤销、Windows/Android 真实 IPC、Native 消息伪造。列入 BUGLOG，不标为通过。
